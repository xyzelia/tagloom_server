# TagLoom · 标签织坊

标签管理与 Prompt 组合：从标签词库里选词、自创标签，整理成人物（外观、服装、表情动作等分类条目）
和场景（场景标签 + 多个人物），汇总成可直接用于生图的 Prompt；也能用一段描述筛出相关标签。
顶部标签页切换「人物 / 场景 / 标签筛选」。

## 功能

| 页面         | 地址                          | 用途                                                                                                     |
| ------------ | ----------------------------- | -------------------------------------------------------------------------------------------------------- |
| 人物列表     | `/tagloom`                    | 按文件夹浏览人物，新建 / 移动 / 改名 / 删除，全局搜索；「更多」里导入人物存档（也可拖到页面上）、文件浏览 |
| 人物文件浏览 | `/tagloom/files`              | 直接浏览 `characters/` 目录里的 JSON 文件，预览、导入为新人物                                            |
| 编辑页       | `/tagloom/edit?path=…`        | 画风串、负面 Prompt、档案、Base、造型组合、角色状态；分类选词、全局标签搜索、Prompt 预览与导出           |
| 标签筛选     | `/tagloom/match`              | 输入一段描述，列出词库里可能相关的标签（按可信度分层），右侧详情栏显示分类层级与来源，可浏览分类         |
| 场景列表     | `/tagloom/scenes`             | 按文件夹浏览场景，新建 / 复制 / 移动 / 改名 / 删除，全文搜索；拖入 NovelAI 图片直接新建场景并导入        |
| 场景编辑     | `/tagloom/scenes/edit?path=…` | 场景条目（全词库搜索 / 自创标签 / 文本）+ 人物快照槽位（分段开关、补充、位置）+ 可选生成参数；预览与导出 |

另外给 AI agent 提供 HTTP
接口和命令行工具（`deno task tagloom-agent`），可以读取人物、查词库、
追加自创标签，见 [../ai-tools/README.md](../ai-tools/README.md)。

场景数据结构与文件格式见 [SCENES_DESIGN.md](SCENES_DESIGN.md)；人物读取与标签追加接口见
[../ai-tools/API.md](../ai-tools/API.md)。

## 启动

在项目根目录（有 `deno.json` 的目录）下：

```sh
deno task dev     # 开发服务，端口固定 5175
deno task start   # 生产服务，端口默认 5175（PORT 可改）
```

两个命令都会读取 `.env`（复制 `.env.example` 后修改；没有 `.env`
时全部用默认值）。

## 配置

### 环境变量（写在 `.env`）

| 变量                       | 默认                                | 说明                                                                                                       |
| -------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `TAGLOOM_CATALOG_PATH`     | `./data/tagloom/tag_catalog.sqlite` | 标签词库文件（检索只读；在词库页导入时会替换它）。文件不存在或打不开时插件照常可用，词库相关功能显示「未进行数据库核查」 |
| `TAGLOOM_ALLOW_RESTRICTED` | 不设置（不显示）                    | 设为 `1` 时显示词库里的受限标签（`restricted=1`，主要是成人内容），其他值都视为不显示                      |
| `PORT`                     | `5175`                              | 生产服务端口（整个服务共用，不只是 TagLoom）；开发服务固定 5175                                            |

这些变量只在服务**启动时**读取；修改后要重启服务。

### 只对 AI 命令行工具生效

| 变量          | 默认                    | 说明                                                                                                                                                                                     |
| ------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TAGLOOM_URL` | `http://localhost:5175` | `deno task tagloom-agent` 连接的服务地址，只接受 `localhost` / `127.0.0.1`。不从 `.env` 读取，需要在命令前设置，例如服务改用 8080 端口时 `TAGLOOM_URL=http://localhost:8080 deno task -q tagloom-agent list` |

### 固定配置（改代码）

- 数据目录：`./data/tagloom`，在宿主组装点 `src/server/plugins.ts`
  传入（`tagloomPlugin({ dataDir })`）。
- 字段与词库分类的对应关系：`share/fields.ts` 的 `categoryPaths`（用分类
  path）。

## 数据位置

| 路径                              | 内容                                                        |
| --------------------------------- | ----------------------------------------------------------- |
| `data/tagloom/characters/`        | 人物 JSON，可以有任意层子文件夹；**人物的身份就是相对路径** |
| `data/tagloom/scenes/`            | 场景 JSON，规则同人物                                       |
| `data/tagloom/tag_catalog.sqlite` | 标签词库（可重新生成，不含用户资料）                        |
| `data/data_source/`               | 词库的来源项目（tags-tree 仓库、CSV），词库页只能从这里选   |

`data/` 不提交到 git。

### 更换或重新生成词库

- **词库导入页**（顶部导航「词库导入」，`/tagloom/catalog`，页面上列有数据来源的仓库链接）：把来源项目放进
  `data/data_source/`，选目录、检测格式后导入；完成后自动重新加载，不用重启。
- **命令行**：`deno task tagloom-catalog tree --repo <tags-tree 仓库目录>`，再按需要
  `deno task tagloom-catalog csv …`。命令行导入后要**重启服务**：服务把词库读进内存，开发服务的热更新也不会重新读取。
- 两种方式都先写临时文件，完成后再替换 `tag_catalog.sqlite`。
- 已保存的人物只存标签的 canonical 和词库版本，不存数字
  id，换库不会把人物绑到错误的标签上。

表结构、导入规则和导入工具用法见 [CATALOG_DB.md](CATALOG_DB.md)。

## 安全

页面接口和 agent
接口都**不鉴权**，只适合可信内网；部署到不可信网络前必须加鉴权。词库页的导入接口也一样：
任何能访问服务的人都能替换词库（只能读 `data/data_source/` 里的文件）。
